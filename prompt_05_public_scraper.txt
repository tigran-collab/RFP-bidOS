The app now has database models, frontend API connection, and rules-based bid/no-bid scoring. Implement a basic public-page scraper foundation only.

Goal:
Create a safe, deterministic scraper system that can fetch simple public procurement pages, find likely bid/opportunity links, and create Opportunity records for review.

Do not implement login scraping yet.
Do not implement Playwright yet unless absolutely necessary.
Do not implement AI/LLM extraction yet.
Do not download RFP files yet.
Do not parse PDFs yet.
Do not submit anything.
Do not scrape aggressively.

Backend requirements:

1. SourceConfig support
Use existing SourceConfig model if present.
Ensure SourceConfig includes:
- name
- source_type
- base_url
- login_url
- enabled
- notes

2. ScrapeRun support
Use existing ScrapeRun model if present.
Ensure ScrapeRun tracks:
- source_name
- started_at
- finished_at
- status
- records_found
- error_message

3. Create backend/app/services/scraper.py

Implement:
- fetch_public_page(url: str) -> str
- extract_candidate_links(html: str, base_url: str) -> list[dict]
- classify_candidate_link(title: str, url: str) -> dict
- scrape_source(source_config) -> dict

The scraper should:
- use requests
- use BeautifulSoup
- respect a normal User-Agent
- timeout after 20 seconds
- only fetch the configured base_url
- extract links whose text or URL contains bid/RFP terms

Useful keywords:
- bid
- bids
- rfp
- rfq
- ifb
- itb
- solicitation
- procurement
- proposal
- quote
- security
- guard
- patrol
- armed
- unarmed

For each candidate:
- title
- url
- source
- source_url
- initial_match_reason
- security_likelihood

4. Opportunity creation
When a candidate appears relevant:
- create an Opportunity record if source_url does not already exist
- title = candidate title
- agency = source_config.name
- source = source_config.name
- source_url = candidate url
- portal_url = source_config.base_url
- status = "Needs Review"
- bid_decision = "Needs Review"
- bid_score = null unless scoring is automatically run
- service_type = guessed only if obvious from title/url

Avoid duplicates by source_url.

5. Add API routes:
- POST /sources/{id}/scrape
- POST /sources/scrape-enabled

POST /sources/{id}/scrape:
- scrape one enabled source
- create ScrapeRun
- return records_found, created_count, skipped_duplicates, errors

POST /sources/scrape-enabled:
- scrape all enabled sources
- return summary

6. Add CLI commands:
- python -m app.cli scrape-source <source_id>
- python -m app.cli scrape-enabled-sources

7. Add seed demo sources command or update seed-demo:
Add 2 to 3 public demo source configs with harmless public procurement URLs.
If unsure, use placeholder disabled sources rather than guessing URLs.
At minimum, seed:

- base_url: https://example.com
- enabled: false
- notes: Placeholder public scraper source

- add button "Scrape Enabled Sources"

If Sources page does not exist, add a simple one or add source scrape controls wherever sources are currently displayed.
