The app now has database models, frontend API connection, rules-based scoring, public scraper foundation, and document downloader. Implement PDF/text extraction only.

Goal:
Parse downloaded documents into extracted text files so RFP content can be searched and used later for compliance matrix generation.

Do not implement AI/LLM features yet.
Do not implement OCR.
Do not implement proposal drafting.
Do not implement login scraping.
Do not implement Playwright.
Do not submit anything.
Do not recursively crawl websites.

Backend requirements:

1. Document model
Use the existing Document model.
Ensure it supports:
- id
- opportunity_id
- filename
- path
- file_type
- sha256
- source_url
- downloaded_at
- parsed_status

If safe and simple, add:
- extracted_text_path
- page_count
- parsed_at
But do not break existing database initialization.

2. Create backend/app/services/parser.py

Implement:

- parse_pdf_to_text(document_id: int, session) -> dict
- parse_document(document_id: int, session) -> dict
- parse_documents_for_opportunity(opportunity_id: int, session) -> dict
- parse_all_documents(session) -> dict

PDF parsing:
- Use PyMuPDF / fitz.
- Extract text page by page.
- Save extracted text under:
  data/processed/opportunity_<opportunity_id>/document_<document_id>.txt
- Include page separators like:
  --- Page 1 ---
- Update Document.parsed_status:
  - "Parsed" if successful
  - "Parse Failed" if failed
  - "Unsupported File Type" if not PDF/text-supported
- Store extracted_text_path if field exists.
- Store page_count if field exists.
- Store parsed_at if field exists.

Supported file types for this phase:
- PDF only required.
- TXT optional.
- DOCX optional only if already easy.
- Do not parse Excel yet.
- Do not OCR scanned PDFs yet.

3. API routes
Add:
- POST /documents/{id}/parse
- POST /opportunities/{id}/parse-documents
- POST /documents/parse-all

POST /documents/{id}/parse:
- parse one document
- return parsing summary

POST /opportunities/{id}/parse-documents:
- parse all documents linked to one opportunity
- return summary

POST /documents/parse-all:
- parse all downloaded documents
- return summary

4. CLI commands
Add:
- python -m app.cli parse-document <document_id>
- python -m app.cli parse-opportunity-documents <opportunity_id>
- python -m app.cli parse-all-documents

5. Frontend
On OpportunityDetail page:
- Show linked documents
- Add Parse Documents button
- Show document parsed_status
- If extracted_text_path exists, show it as plain text path only
- Show simple result message after parsing
